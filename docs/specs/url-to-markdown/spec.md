# URL → Markdown → LLM

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 뽑아 보여 주고, 복사·다운로드하거나 ChatGPT·Claude로 바로 넘기는 한 페이지짜리 서비스입니다.

승인된 화면: [prototype.html](prototype.html). 화면 배치, 상태(변환 중·결과·오류), 문구의 기준이며 구현용 코드는 아닙니다.

## 사용자에게 보이는 결과

화면 위에서 아래 순서: 헤더(다크모드 토글) → URL 입력 → 프롬프트 → 본문 영역(빈 상태/변환 중/오류/결과) → 내보내기(결과가 있을 때만).

1. **입력**: URL 입력란에 주소를 붙여넣고, 입력란 오른쪽 안에 있는 화살표(→) 버튼(또는 Enter)으로 변환을 실행합니다. 별도의 "변환" 텍스트 버튼은 없습니다. 입력란 안의 지우기(✕) 버튼은 값이 있을 때만 보이며, 누르면 누르면 입력과 결과가 모두 초기 상태로 돌아갑니다.
2. **변환**: 페이지 본문을 Markdown으로 추출합니다. 변환 중에는 로딩 상태가 보입니다.
3. **결과 확인**: 페이지 제목과 저자를 담은 헤더 아래에 렌더링된 Markdown이 표시됩니다. 저자를 알 수 없으면 저자 항목은 생략합니다.
4. **내보내기**
   - 복사하기: Markdown 원문을 클립보드에 복사하고, 복사됐다는 피드백을 보여 줍니다.
   - .md 다운로드: Markdown 원문을 `.md` 파일로 저장합니다. 파일명은 페이지 제목에서 만듭니다.
   - ChatGPT로 열기 / Claude로 열기: 아래 "LLM로 열기" 규칙을 따릅니다.
5. **프롬프트**
   - 프리셋: 요약해줘 / 한국어로 번역해줘 / 쉽게 설명해줘 중 하나를 고르거나 선택하지 않을 수 있습니다(기본은 선택 없음).
   - 프리셋 옆 "직접 입력"을 고르면 텍스트 입력란이 나타나고, 입력한 문구가 프롬프트가 됩니다. 이 값은 저장하지 않으며 새로고침하면 사라집니다.
   - 프롬프트를 고르지 않으면 본문만 전달합니다.
   - 프롬프트 영역은 URL 입력 바로 아래에 항상 보이며, 변환 전에도 고를 수 있습니다. 선택은 변환·재변환 중에도 유지되고, 지우기를 누르면 초기화됩니다.
6. **다크모드**: 토글로 라이트/다크를 전환합니다.

## LLM로 열기 (확정)

본문은 URL 길이 한도 때문에 링크에 담지 않습니다. 버튼을 누르면 **프롬프트(선택 시) + Markdown 본문**을 클립보드에 복사하고, 새 탭에서 ChatGPT 또는 Claude 새 대화를 엽니다. 화면에는 "클립보드에 복사했으니 붙여넣으세요"라는 안내를 보여 줍니다. 프롬프트는 본문 앞에 붙습니다.

## 수용 기준

- 유효한 URL을 넣으면 제목, 저자(있을 때), 렌더링된 Markdown이 보인다.
- 지우기를 누르면 입력, 결과, 오류, 직접 입력 문구가 모두 비워진다.
- 복사하기로 클립보드에 들어간 내용이 화면에 보이는 Markdown 원문과 같다.
- 다운로드한 `.md` 파일 내용이 같은 원문이다.
- 프리셋 선택 후 ChatGPT·Claude로 열기를 누르면 클립보드가 "프롬프트 + 빈 줄 + 본문"이 되고, 프롬프트를 고르지 않으면 본문만 들어간다.
- "직접 입력"을 고르기 전에는 텍스트 입력란이 보이지 않고, 고른 뒤에만 나타난다.
- 잘못된 URL, 접근 실패, 본문 추출 실패는 각각 화면에 오류 상태로 표시되며 입력은 유지된다.
- 다크모드 토글이 전체 화면에 일관되게 적용된다.
- 좁은 화면에서도 모든 버튼과 결과가 숨겨지지 않고 세로로 쌓인다.

## 확정된 제약과 이유

- **본문 추출은 `defuddle` 라이브러리를 사용한다.** 사용자 요구입니다. 서버에서 `linkedom`과 함께 쓰는 구성이 동작함을 별도 폴더에서 확인했습니다(defuddle 0.19.5, `example.com`에서 제목·본문 추출 성공). 다른 추출 방식으로 대체하지 않습니다.
- **변환은 서버에서 수행한다.** 브라우저에서 임의 사이트를 직접 가져오면 CORS로 막히기 때문입니다.
- **LLM 전달은 클립보드 방식으로 한다.** 긴 글이 URL 한도를 넘어 잘리거나 실패하는 것을 막기 위해 사용자가 선택했습니다.
- UI는 `docs/decisions/ui-composition.md`를 따릅니다(shadcn 구성, semantic token, 공통 shell, loading/empty/error/success 상태 설계). 이 문서가 컴포넌트 선택과 화면 구성을 규정하므로 여기서 다시 적지 않습니다.

## 가정 (덮어쓸 수 있음)

- 입력은 `http`/`https` URL만 받는다.
- 한 번에 한 URL만 처리하며 변환 기록은 저장하지 않는다.
- ChatGPT·Claude 새 대화는 각각 `https://chatgpt.com/`, `https://claude.ai/new`로 연다. 프롬프트를 `?q=`로 미리 채우는 기능은 쓰지 않는다(클립보드로 일원화).
- 로그인이 필요한 페이지, 자바스크립트로만 그려지는 페이지는 지원하지 않으며 추출 실패 오류로 처리한다.
- 다크모드는 시스템 설정을 초기값으로 쓰고, 토글 선택은 브라우저에 기억해도 된다.
- 프롬프트 프리셋 문구는 버튼 이름 그대로 전달한다.

## 남은 위험

- 일부 사이트는 서버에서 가져오는 요청을 차단하거나 JS 렌더링 전 HTML에 본문이 없어 추출이 실패할 수 있습니다. 오류 상태로 안내하는 것까지만 보장합니다.
- 클립보드 쓰기는 사용자 클릭 직후에만 허용되는 브라우저가 있어, 새 탭을 여는 동작과 순서가 충돌하면 복사가 실패할 수 있습니다. 복사 실패 시에도 안내가 보여야 합니다.
- ChatGPT·Claude의 새 대화 주소는 제품 쪽에서 바뀔 수 있습니다.
